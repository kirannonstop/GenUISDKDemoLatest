🎨 GenUI Custom Catalog - Complete Flow

Creating Your Own Custom Widgets

Instead of using GenUI's default catalog (card, column, text),
you can create custom widgets (RecipeCard, IngredientList, NutritionInfo)
and let AI use them!

🔧 Default Catalog

  • 18 pre-built widgets
  • card, column, text, button, etc.
  • AI composes them together
  • Generic UI appearance
  • No custom code needed

🎨 Custom Catalog

  • You create custom widgets
  • RecipeCard, IngredientList, etc.
  • AI fills in the data
  • Branded, custom designs
  • Full control over UI/UX
1

Create Your Custom Flutter Widget

First, build a normal Flutter widget with all the properties you want:

RecipeCard Widget (Flutter)
class RecipeCard extends StatelessWidget { final String dishName; final String description; final String mealType; final int prepTime; final int cookTime; final List<String> ingredients; final VoidCallback? onSaveFavorite; final VoidCallback? onGetRecipe; const RecipeCard({ required this.dishName, required this.description, // ... other required params }); @override Widget build(BuildContext context) { return Card( child: Column( children: [ // Beautiful header with gradient Container( decoration: BoxDecoration( gradient: LinearGradient( colors: [Colors.orange.shade400, Colors.orange.shade600], ), ), child: Text(dishName), ), // Time info, calories, ingredients // Action buttons: Save, Recipe, etc. ], ), ); } }
✅ What You Did:

• Created a custom Flutter widget with your own design

• Added all properties (dishName, prepTime, etc.)

• Designed beautiful UI with gradients, chips, buttons

• Added callback functions for button actions

2

Wrap Widget in CatalogItem

Now, create a CatalogItem that tells GenUI SDK about your widget:

CatalogItem Definition
final recipeCard = CatalogItem( // 1. Name that AI will use to reference this widget name: 'RecipeCard', // 2. Schema defining what data this widget needs dataSchema: S.object( properties: { 'dishName': A2uiSchemas.stringReference( description: 'Name of the dish' ), 'description': A2uiSchemas.stringReference( description: 'Brief description' ), 'prepTime': A2uiSchemas.stringReference( description: 'Preparation time' ), 'cookTime': A2uiSchemas.stringReference( description: 'Cooking time' ), 'mealType': A2uiSchemas.stringReference( description: 'breakfast, lunch, dinner, snack' ), }, required: ['dishName', 'description'], ), // 3. Builder function that creates your widget widgetBuilder: (context) { final data = context.data as Map<String, Object?>?; // Subscribe to data values (reactive updates) final dishNameNotifier = context.dataContext .subscribeToString(data?['dishName'] as Map?); final descriptionNotifier = context.dataContext .subscribeToString(data?['description'] as Map?); // Return your custom widget wrapped in ValueListenableBuilder return ValueListenableBuilder<String?>( valueListenable: dishNameNotifier, builder: (context, dishName, _) { return ValueListenableBuilder<String?>( valueListenable: descriptionNotifier, builder: (context, description, _) { return RecipeCard( dishName: dishName ?? '', description: description ?? '', // ... other properties ); }, ); }, ); }, );
🔑 Key Components of CatalogItem:

1. name: "RecipeCard" - AI uses this to reference your widget

2. dataSchema: JSON schema defining what data your widget needs

3. widgetBuilder: Function that builds your Flutter widget from data

💡 What's Happening:

dataSchema tells AI: "RecipeCard needs dishName, description, prepTime, etc."

subscribeToString() creates reactive listeners for data changes

ValueListenableBuilder rebuilds widget when data changes

widgetBuilder extracts data and passes it to your RecipeCard widget

⬇️
3

Add to Catalog & Pass to GenUiConversation

Create a catalog with your custom widgets and pass it to GenUiConversation:

Initialize GenUI with Custom Catalog
// Create custom catalog items final recipeCard = CatalogItem(/* ... */); final ingredientList = CatalogItem(/* ... */); final nutritionInfo = CatalogItem(/* ... */); // Create catalog combining default + custom items final customCatalog = Catalog([ // Include default catalog items (card, column, text, etc.) ...CoreCatalog.asCatalog().items, // Add your custom items recipeCard, ingredientList, nutritionInfo, ]); // Initialize GenUiConversation with custom catalog final _genUiConversation = GenUiConversation( contentGenerator: myContentGenerator, catalog: customCatalog, // ← Your custom catalog! );
✅ What Happened:

• Combined default catalog items (18 widgets) with your 3 custom widgets

• Now AI has access to 21 total widgets!

• AI can choose to use RecipeCard, IngredientList, or NutritionInfo

5

GenUI SDK Builds Your Custom Widget

Internal Process:

🔄 What Happens Inside GenUI SDK

Step 1: GenUiManager Receives Component

• Sees component name: "RecipeCard"

• Stores component data in DataModel

Step 2: GenUiSurface Looks Up Catalog

• Searches catalog for "RecipeCard"

• Finds YOUR CatalogItem definition

Step 3: Calls widgetBuilder

• Calls: recipeCard.widgetBuilder(context)

• Passes component data as context.data

Step 4: Your Builder Runs

• Extracts data: dishName, description, etc.

• Creates ValueListenableBuilders for reactivity

• Returns your RecipeCard widget!

Step 5: Widget Appears!

• Your beautiful custom RecipeCard renders

• User sees gradient header, chips, buttons

• Everything styled exactly as you designed!

🎯 Summary: How Custom Catalog Works

👨‍💻 What You Do

  • Create custom Flutter widget
  • Define CatalogItem with schema
  • Add widgetBuilder function
  • Register in custom catalog
  • Pass to GenUiConversation

🤖 What AI Does

  • Sees your catalog items in tools
  • Chooses RecipeCard for recipes
  • Fills in all the data fields
  • Returns component structure

⚙️ What GenUI SDK Does

  • Receives component: {"RecipeCard": {dishName: "...", ...}}
  • Looks up "RecipeCard" in your catalog
  • Calls your widgetBuilder with data
  • Your builder returns RecipeCard widget
  • Widget appears with your custom design!
